\noindent The selected parameter set contains one nonzero pair coefficient, $k_{\ce{MEA},\ce{H2O}}=-0.052$.
This value was retained from an earlier MEA--water record, but its source dataset, fitting procedure, and uncertainty were not recovered.
The earlier record also used a different neutral association-scheme combination from the selected 2B/2B record.
This inconsistency must be resolved and the calculations repeated before the parameter set can be presented as source-complete.
No $k_{ij}$ value was estimated from the NCCC absorber rows in this study.
