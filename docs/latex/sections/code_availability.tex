    \section*{Code Availability}
        The Python code for the MEA absorber benchmark, including the solver settings and thermodynamic driving-force calculations used in this study, is available in the \href{https://github.com/tannerpolley/MEA-Absorption-Column}{project repository}; the committed manuscript version used for this submission is tagged as \texttt{nce-submission-preprint-v1}. The routine ePC-SAFT validation rows use the vendored \texttt{MEA\_CO2\_H2O\_ionic\_fit} dataset and the \texttt{epcsaft} Python package version 1.5.0 from \url{https://github.com/tannerpolley/ePC-SAFT}, commit \texttt{e4ee304721ac6670120e69ef260a596ea3c3fe9c}~\cite{Polley2026epcsaft}. No archival DOI has been minted for either repository at the time of manuscript preparation.
