    \section*{Code Availability}
        The Python code for the MEA absorber benchmark, including the solver settings and thermodynamic driving-force calculations used in this study, is available in the \href{https://github.com/tannerpolley/MEA-Absorption-Column}{project repository}; the committed submission-readiness baseline used for this revision is \texttt{e42ee001006e6e9449e718bcf7815cae2f8429b5}. The routine ePC-SAFT validation rows use the vendored \texttt{MEA\_CO2\_H2O\_ionic\_fit} dataset and the \texttt{epcsaft} Python package version 1.5.0 from \href{https://github.com/tannerpolley/ePC-SAFT}{https://github.com/tannerpolley/ePC-SAFT}, commit \texttt{e4ee304721ac6670120e69ef260a596ea3c3fe9c} \cite{Polley2026epcsaft}. No archival DOI has been minted for either repository at the time of manuscript preparation.
