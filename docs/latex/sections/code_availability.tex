    \section*{Code Availability}
The Python code for the MEA absorber calculations, including the solver settings and thermodynamic driving-force calculations used in this study, is available in the \href{https://github.com/tannerpolley/MEA-Absorption-Column}{project repository}. The manuscript source and calculation records correspond to the \href{https://github.com/tannerpolley/MEA-Absorption-Column/tree/nce-mea-only-pre-mdea-2026-08-25}{tagged revision dated 2026-08-25}. The reported ePC-SAFT calculations use parameter set \texttt{MEA\_CO2\_H2O\_ionic\_fit}, dataset SHA-256 \texttt{b4b5c2c2\allowbreak{}55790f64\allowbreak{}ee20ca0b\allowbreak{}070a007c\allowbreak{}2fee4fef\allowbreak{}22653f57\allowbreak{}8356bb34\allowbreak{}39d5ccdb}, and the non-editable \texttt{epcsaft} 0.2 wheel through its public \texttt{Parameters--Mixture--State} API. The ePC-SAFT source revision is \texttt{b64f6df9\allowbreak{}06489cb1\allowbreak{}32792641\allowbreak{}c5be2ee8\allowbreak{}f404b114}; the wheel SHA-256 is \texttt{a505d20a\allowbreak{}c9019e9b\allowbreak{}4edbad16\allowbreak{}df80166b\allowbreak{}6e082170\allowbreak{}ef2a2f00\allowbreak{}2d897269\allowbreak{}e756d0d9}. The package evaluates derivatives with CppAD automatic differentiation and is cited in the software references~\cite{Polley2026epcsaft}. Changing the parameter set or package requires recalculation of the affected results. No archival DOI had been minted for the absorber repository at the time of manuscript preparation; the tagged revision identifies the available code record until an archive is issued.
