    \section*{Code Availability}
The Python absorber model is maintained in the \href{https://github.com/tannerpolley/MEA-Absorption-Column}{project repository}.
The \href{https://github.com/tannerpolley/MEA-Absorption-Column/tree/0d4e552e15fdf9ee17edc64908c3a04a6525f98b}{revision dated 2026-08-25} identifies only the historical six-species comparison, using \texttt{MEA\_CO2\_H2O\_ionic\_fit}.
The coupled nine-species calculations use the parameterization in \cref{sec:selected-reactive-inputs}, an immutable \texttt{epcsaft} wheel, native thermodynamic derivatives and differentiated column equations~\cite{Polley2026epcsaft}.
Their exact software and parameter identities, evaluated source files and reproduction commands are recorded in \texttt{REPRODUCE.md} and the retained run records.
The August revision is not a release of the coupled calculation files; no public archival identifier for those files is supplied here.
