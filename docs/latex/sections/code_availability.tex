    \section*{Code Availability}
        The Python code for the MEA absorber benchmark, including the solver settings and thermodynamic driving-force calculations used in this study, is available in the \href{https://github.com/tannerpolley/MEA-Absorption-Column}{project repository}; the committed manuscript version used for this submission is tagged as \texttt{nce-submission-preprint-v2}. The routine ePC-SAFT validation rows use the vendored \texttt{MEA\_CO2\_H2O\_ionic\_fit} dataset and the \texttt{epcsaft} Python package version 1.5.0 from the public GitHub repository \url{https://github.com/tannerpolley/ePC-SAFT}. The package release and source commit used for this work are cited in the software reference~\cite{Polley2026epcsaft}. No archival DOI has been minted for the absorber repository at the time of manuscript preparation; the cited GitHub tag should be used for reproduction until an archive is issued.
