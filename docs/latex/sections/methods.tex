    \section{Methods}
        For all three numerical methods, the packed-column problem can be written as the boundary value problem
        \begin{align}
            \begin{cases}
            \displaystyle
            \frac{d \mathbf{y}}{dz} = \mathbf{f}\bigl(z, \mathbf{y}(z)\bigr) \\
            \mathbf{y}(0) = \boldsymbol{\alpha}, \quad \mathbf{y}(H) = \boldsymbol{\beta},
            \end{cases}
            &&
            \begin{matrix}
            \left(\text{component units of }\mathbf{y}\,\unit{m^{-1}}\right)\\
            \left(\text{component units of }\mathbf{y}\right)
            \end{matrix}
        \end{align}
        Several numerical methods can solve this kind of packed-absorption-column BVP. This benchmark compares shooting, finite difference, and collocation on the same governing equations. Shooting and finite difference are useful comparison methods because they expose different initialization and discretization behavior. Collocation is used as the reference method for the reported benchmark rows because it gives direct control over mesh refinement and residual reporting. Speed and robustness are measured outcomes of the runs, not assumed method rankings.

        \subsection{Shooting Method}
            The shooting calculation guesses the unknown inlet-side state values, integrates the absorber balances across the packed height, and adjusts the guess until the outlet-side boundary conditions are met. For a guessed parameter vector $\mathbf{p}$, one integration gives $\mathbf{y}(H;\mathbf{p})$. The boundary mismatch is
                \begin{align}
                    \mathbf{F}(\mathbf{p}) = \mathbf{y}\bigl(H; \mathbf{p}\bigr) - \boldsymbol{\beta}
                    && \left(\text{component units of }\mathbf{y}\right).
                \end{align}
                The root-finding problem is therefore
                \begin{align}
                    \mathbf{F}(\mathbf{p}) &= \mathbf{0}
                    && \left(\text{component units of }\mathbf{y}\right),
                \end{align}
                with each nonlinear iteration requiring another packed-column integration. This method is attractive when the profile is smooth and a good inlet-side guess is available. It is less reliable when the column contains sharp thermal or mass-transfer features, because a small inlet-state error can grow across the bed before the outlet mismatch is evaluated. The results section uses shooting for that reason: it is a useful speed comparison on smoother cases, but it is not the routine validation method for the NCCC thermal-profile rows.

        \subsection{Finite Difference}
            The finite-difference calculation replaces the continuous axial derivatives with mesh-based algebraic residuals. The packed height is divided into $N$ intervals with
                \begin{align}
                    z_k = k\,\Delta z, \quad k = 0, 1, 2, \ldots, N,
                    && \left(\unit{m}\right)
                \end{align}
                where $\Delta z=H/N$. The nodal state $\mathbf{y}^k$ approximates the absorber state at $z_k$,
                \begin{align}
                    \mathbf{y}^k \;\approx\; \mathbf{y}\bigl(z_k\bigr)
                    && \left(\text{component units of }\mathbf{y}\right).
                \end{align}
                Interior derivatives are represented with central differences,
                \begin{align}
                    \frac{d \mathbf{y}}{dz}\biggr\rvert_{z=z_k}
                    \approx
                    \frac{\mathbf{y}^{k+1} - \mathbf{y}^{k-1}}{2\,\Delta z},
                    \quad 
                    k = 1, 2, \ldots, N-1
                    && \left(\text{component units of }\mathbf{y}\,\unit{m^{-1}}\right).
                \end{align}
                The boundary nodes enforce the inlet and outlet conditions,
                \begin{align}
                    \mathbf{y}^0 = \boldsymbol{\alpha}, 
                    \quad 
                    \mathbf{y}^N = \boldsymbol{\beta},
                    && \left(\text{component units of }\mathbf{y}\right)
                \end{align}
                for the components fixed by the mixed column boundary specification. Collecting the finite-difference equations and boundary equations gives
                \begin{align}
                    \mathcal{R}\Bigl(\mathbf{y}^0,\, \mathbf{y}^1,\, \dots,\, \mathbf{y}^N\Bigr) 
                    = \mathbf{0},
                    && \left(\text{component residual units}\right)
                \end{align}
                over all nodal unknowns. Finite difference is included because it gives a direct algebraic discretization check against shooting and collocation. In this absorber problem, however, an algebraic solve can converge to a mathematically consistent but physically poor branch unless acceptance checks are applied after convergence. The finite-difference rows are therefore interpreted through capture, temperature, and residual evidence rather than by solver success alone.

        \subsection{Collocation BVP Method}
            The collocation calculation uses an adaptive residual-controlled BVP routine. It is not a custom orthogonal-collocation code built from user-selected Legendre or Chebyshev points. For reproducibility, each run reports the starting mesh size, maximum node count, solver tolerance, boundary-condition tolerance, initialization profile, scaling, final residual norm, and convergence message.

            \subsubsection*{Solver Configuration and Initialization}
                The method starts with an axial mesh over the packed height and an initial profile for every state variable on that mesh. For this absorber model, the profile includes liquid and vapor apparent molar flow rates, liquid and vapor enthalpy flows, and pressure. The starting profile may be constant, linearly interpolated between boundary values, or reused from a nearby operating point. This choice matters because chemical equilibrium, fugacity, enhancement-factor, and transport calculations are all nonlinear functions of the local state. A poor starting profile can push some mesh intervals outside the physical domain; a profile that respects inlet flows, temperatures, and pressure gives the nonlinear solve a better starting point.

            \subsubsection*{Collocation Formulation}
                Instead of integrating from one end of the column to the other, collocation represents each state variable with piecewise polynomial functions over the mesh intervals. Within each interval, the polynomial derivative is forced to match the governing-equation residual at selected internal points. The boundary conditions are enforced at the same time. This turns the two-point BVP into one coupled nonlinear algebraic problem over the whole column. The key difference from shooting is that both column ends influence the solution at once, so the method does not depend on guessing one boundary and propagating that guess through the full packed height.

                Let the mesh be $0=z_0<z_1<\cdots<z_N=H$. On interval $[z_j,z_{j+1}]$, the state is approximated by a local polynomial $\mathbf{p}_j(z)$:
                \begin{align}
                    \mathbf{y}(z) &\approx \mathbf{p}_j(z),
                    \qquad z_j \le z \le z_{j+1}
                    && \left(\text{component units of }\mathbf{y}\right).
                \end{align}
                At each collocation point $z_{j,q}$ inside the interval, the polynomial derivative is constrained to match the absorber model:
                \begin{align}
                    \mathbf{p}'_j(z_{j,q})
                    -\mathbf{f}\left(z_{j,q},\mathbf{p}_j(z_{j,q})\right)
                    &= \mathbf{0},
                    \qquad q=1,\ldots,s
                    && \left(\text{component units of }\mathbf{y}\,\unit{m^{-1}}\right).
                \end{align}
                Neighboring interval polynomials must also meet at the mesh nodes,
                \begin{align}
                    \mathbf{p}_{j-1}(z_j)-\mathbf{p}_{j}(z_j)
                    &=\mathbf{0},
                    \qquad j=1,\ldots,N-1
                    && \left(\text{component units of }\mathbf{y}\right),
                \end{align}
                while the boundary conditions close the system:
                \begin{align}
                    \mathbf{B}\left(\mathbf{p}_0(0),\mathbf{p}_{N-1}(H)\right)
                    &= \mathbf{0}
                    && \left(\text{boundary residual units}\right).
                \end{align}
                Collecting the polynomial coefficients and mesh-state values into $\mathbf{U}$ gives the nonlinear algebraic problem solved by the collocation routine:
                \begin{align}
                    \mathbf{R}(\mathbf{U}) &= \mathbf{0}
                    && \left(\text{scaled residual units}\right).
                \end{align}

            \subsubsection*{Nonlinear Solve and Mesh Refinement}
                The coupled algebraic system is solved iteratively. At each iteration, the model evaluates governing-equation residuals, boundary residuals, and the scaling used to put variables on comparable magnitudes. The solver then updates the mesh-state values until the polynomial profile better satisfies both the differential equations and the boundary conditions. For this absorber model, one residual evaluation is not cheap: each axial point requires chemical-equilibrium, thermodynamic driving-force, transport-property, enhancement-factor, and flux calculations. For that reason, the benchmark records more than a success flag. It reports residual norm, boundary residual, runtime, mesh size, and solver message.

                After a candidate solution is found on the current mesh, the method estimates where the collocation residual is largest. Intervals with larger residuals receive more mesh nodes, and the nonlinear solve is repeated on the refined mesh. This is useful for packed-column absorption because temperature and concentration profiles can be smooth through most of the bed but sharper near a thermal bulge or thermodynamic pinch. A fixed coarse mesh can miss those regions, while a very fine uniform mesh makes every solve larger. Adaptive refinement puts nodes where the solution needs them, within the maximum-node limit reported for the benchmark.

            \subsubsection*{Benchmark Role and Reported Diagnostics}
                In this work, collocation is a benchmarked solver choice, not a separate methodological contribution. It is the primary method for the NCCC one-bed validation because it handles mixed boundary conditions and localized profile changes better than propagating an initial-value guess through the full column. Its performance still depends on scaling, initialization, mesh limits, residual tolerances, and whether the property models stay inside their valid domains. The benchmark output records adaptive mesh behavior, convergence message, boundary residual norm, runtime, and validation error so that robustness and speed claims stay tied to the actual runs.

        \subsection{Reproducibility and Numerical Settings}
            The benchmark calculations were run in Python 3.13 with fixed package versions. Each result row records the case, method setting, convergence message, residual information, capture error, temperature error where measured taps are available, runtime, mesh settings, solver tolerances, initialization notes, and thermodynamic model. The full benchmark data record also retains Python version, platform, and package-version information. The same reporting fields are used for all solver paths, so numerical behavior can be compared directly across methods.

            Accepted one-bed NCCC rows use the collocation BVP path with 21 starting mesh points, a solver tolerance of 0.5, a boundary-condition tolerance of 0.001, and a maximum of 1000 mesh nodes. The solve scales flow and enthalpy states, uses bounded state transforms to keep property calls inside their physical domains, and applies the ePC-SAFT CO$_2$ fugacity correction in the ePC-SAFT rows. These settings define the common acceptance basis for K18, K19, and 1C--6C. K20 and 7C were attempted with the same bounded-state solver formulation but did not satisfy the common accepted-row gate.

            The thermodynamic benchmark includes the Henry-law baseline and the ePC-SAFT driving-force calculation. In the ePC-SAFT calculation, the equation of state supplies the CO$_2$ fugacity coefficients while the same concentration-based chemical-equilibrium calculation remains active for the routine one-bed NCCC campaign. Only the CO$_2$ fugacity driving force changes in the accepted validation rows. Chemical equilibrium, enhancement factor, transport-property correlations, and governing balances are held fixed. Pressure is specified for each ePC-SAFT phase state, and density initialization is used only to speed the numerical solve. The selected ePC-SAFT parameter set is \texttt{MEA\_CO2\_H2O\_ionic\_fit}; its parameter summary is given in Appendix~\ref{sec:appendix-properties}. The liquid phase uses the ionic terms directly; the vapor phase uses the same fugacity-coefficient framework with only neutral species present. A separate full ionic speciation sweep routes ePC-SAFT activity-related quantities into the chemical-equilibrium calculation before evaluating the fugacity driving force. That sweep is reported as a timing and feasibility boundary, while the repeated one-bed campaign uses the faster fugacity-only ePC-SAFT path.

        \subsection{Validation Gate and Reported Metrics}
            A row is included in the routine validation aggregate only when the selected solver reports success, the boundary residual norm is at most 1.0, the predicted capture remains in the physical range of 0--100\%, and the run finishes within the prescribed wall-time limit. There is no temperature-RMSE acceptance gate, and guard or invalid-state counts do not exclude a row unless such a gate is explicitly configured. Runs that fail the accepted-row gate are still retained as attempted-row evidence, but they are not averaged with accepted rows. This distinction is important because some failures still carry useful information about conditioning, guard activation, or runtime.

            Capture error is reported in percentage points relative to the measured pilot-plant capture. Temperature-profile error is reported only for cases with measured axial temperature taps. Runtime is the wall-clock model runtime recorded by the benchmark workflow, not an external manual timing. Domain-guard and invalid-state counts are reported as numerical-conditioning diagnostics: they identify solver iterations that left the physically valid property domain during an attempted solve. K19 remains in the accepted set because both thermodynamic rows meet the solver, boundary-residual, physical-capture, and timeout gates even though each row records 108 invalid-state and guard-penalty events.
