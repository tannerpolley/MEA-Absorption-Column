    \section{Methods}
        For all three numerical methods, the packed-column problem can be written as the boundary value problem
        \begin{align}
            \begin{cases}
            \displaystyle
            \frac{d \mathbf{y}}{dz} = \mathbf{f}\bigl(z, \mathbf{y}(z)\bigr) \\
            \mathbf{y}(0) = \boldsymbol{\alpha}, \quad \mathbf{y}(H) = \boldsymbol{\beta},
            \end{cases}
            &&
            \begin{matrix}
            \left(\text{component units of }\mathbf{y}\,\unit{m^{-1}}\right)\\
            \left(\text{component units of }\mathbf{y}\right)
            \end{matrix}
        \end{align}
        Several numerical methods can solve this kind of packed-absorption-column BVP. This benchmark compares shooting, finite difference, and collocation on the same governing equations. Shooting and finite difference are useful comparison methods because they expose different initialization and discretization behavior. Collocation is used as the reference method for the reported benchmark rows because it gives direct control over mesh refinement and residual reporting. Speed and robustness are measured outcomes of the runs, not assumed method rankings.

        \subsection{Shooting Method}
            The shooting method solves a boundary value problem (BVP) by converting it into a set of initial value problems (IVPs). The core idea is to guess the unknown initial conditions, integrate the differential equations forward in one ``shot,'' and check whether the final boundary conditions are satisfied. If the final boundary conditions are not met, the initial guess is refined and the process is repeated. This approach uses standard IVP solvers, such as Runge--Kutta methods, together with a root-finding method such as Newton--Raphson, bisection, or a secant method. Its main advantage is simplicity: an IVP solver and a mismatch correction are enough to define the procedure. Its main weakness is sensitivity. Small errors in the guessed boundary values can grow across a long or stiff column, and each correction requires another integration. The steps are:

            \subsubsection*{Integrate as an IVP (``Shoot'')}
                For a given guess $\mathbf{p}$:
                \begin{enumerate}
                    \item Construct the initial condition $\mathbf{y}(0) = \boldsymbol{\alpha}$.
                    \item Integrate the ODE system $\frac{d\mathbf{y}}{dz} = \mathbf{f}(z,\mathbf{y})$ from $z=0$ to $z=H$ using an IVP solver (e.g., a Runge--Kutta method).
                    \item Record the final solution $\mathbf{y}(H;\mathbf{p})$ at $z=H$.
                \end{enumerate}
                This completes one \emph{shoot} from $z=0$ to $z=H$.

            \subsubsection*{Mismatch Function}
                After integrating with the guess $\mathbf{p}$, define the \emph{mismatch function}:
                \begin{align}
                    \mathbf{F}(\mathbf{p}) = \mathbf{y}\bigl(H; \mathbf{p}\bigr) - \boldsymbol{\beta}
                    && \left(\text{component units of }\mathbf{y}\right).
                \end{align}
                This vector $\mathbf{F}(\mathbf{p})$ measures how far the computed solution at $z=H$ is from the required boundary condition $\boldsymbol{\beta}$.

            \subsubsection*{Root-Finding on the Mismatch}
                To solve the BVP, we need $\mathbf{F}(\mathbf{p}) = \mathbf{0}$. Thus, the unknown initial values $\mathbf{p}$ must be adjusted until
                \begin{align}
                    \mathbf{y}\bigl(H,\mathbf{p}\bigr) &= \boldsymbol{\beta}
                    && \left(\text{component units of }\mathbf{y}\right).
                \end{align}
                Any standard root-finding algorithm capable of handling multiple variables can be used here. Each iteration calls the IVP solver anew (the ``shoot''), refines $\mathbf{p}$, and re-checks the mismatch at $z=H$ until $\|\mathbf{F}(\mathbf{p})\|$ is sufficiently small.

            \subsubsection*{Summary}
                The shooting method, while conceptually straightforward, can encounter several complications when applied to a system of this nature. First, if the underlying equations are stiff or exhibit rapid changes, small numerical inaccuracies in the guessed initial conditions can amplify significantly over the integration domain, making the procedure unstable or very sensitive to perturbations. Second, if the domain is large or the solution features steep gradients, one might need a very accurate or adaptive IVP solver for each ``shoot,'' which can be computationally expensive. Additionally, good initial guesses for the unknown boundary conditions may be hard to find, especially in higher-dimensional problems, which can increase iteration counts. Finally, repeated integration for each iteration of a root-finding method (e.g., Newton's method or secant-like approaches) can become costly, and if Jacobian information is not readily available, approximation errors in the gradient of the mismatch function can slow the solve. These characteristics matter when solving the boundary value problem due to the stiffness and non-linearity of the model and will be further discussed below.

        \subsection{Finite Difference}
        The finite difference method (FDM) approximates derivatives with discrete difference quotients across a spatial mesh. By discretizing each differential equation between the boundary conditions, the original BVP is transformed into a system of algebraic equations. Each unknown state is represented at the mesh nodes, and finite-difference formulas link neighboring nodal values. The boundary conditions then anchor the solution at the domain edges. For the absorber model, the finite-difference system includes the species flow rates, phase enthalpy flows, and pressure state, coupled through the original differential equations. The method's main advantages are clarity of formulation and straightforward extension to mixed boundary conditions. Its main challenges are grid sensitivity, nonlinearity, stiffness, and the computational cost of solving the coupled algebraic system. The solution steps are summarized below.

            \subsubsection*{Discretize the Domain}
                Divide the interval $[0,H]$ into $N$ sub-intervals of equal length $\Delta z = \frac{H}{N}$. Define the grid points:
                \begin{align}
                    z_k = k\,\Delta z, \quad k = 0, 1, 2, \ldots, N,
                    && \left(\unit{m}\right)
                \end{align}
                so that $z_0 = 0$ and $z_N = H$. Let $\mathbf{y}^k$ be the approximation to $\mathbf{y}$ at $z = z_k$:
                \begin{align}
                    \mathbf{y}^k \;\approx\; \mathbf{y}\bigl(z_k\bigr)
                    && \left(\text{component units of }\mathbf{y}\right).
                \end{align}
                Each component of $\mathbf{y}^k$ corresponds to one of the six unknown functions ($F^{\liq}_{\mathrm{CO_2}}$, $F^{\liq}_{\mathrm{H_2O}}$, $F^{\vap}_{\mathrm{CO_2}}$, $F^{\vap}_{\mathrm{H_2O}}$, $\dot{H}_l$, $\dot{H}_v$).

            \subsubsection*{Approximate Derivatives by Finite Differences}
                A common choice is to use central differences for interior points:
                \begin{align}
                    \frac{d \mathbf{y}}{dz}\biggr\rvert_{z=z_k}
                    \approx
                    \frac{\mathbf{y}^{k+1} - \mathbf{y}^{k-1}}{2\,\Delta z},
                    \quad 
                    k = 1, 2, \ldots, N-1
                    && \left(\text{component units of }\mathbf{y}\,\unit{m^{-1}}\right).
                \end{align}
                If your system dictates or if you prefer simpler expressions, you might use forward or backward differences in some cases, but central differences typically provide higher accuracy for the same grid spacing. Thus, for each $k=1,\dots,N-1$, we replace \(\frac{d \mathbf{y}}{dz}\bigl(z_k\bigr)\) with the discrete difference. This transforms each continuous ODE \(\frac{d y_i}{dz} = f_i\bigl(z, y_1, y_2, \ldots, y_6\bigr)\) into an algebraic equation involving $\mathbf{y}^{k-1}$, $\mathbf{y}^k$, and $\mathbf{y}^{k+1}$.

            \subsubsection*{Impose Boundary Conditions}
                At $k=0$ and $k=N$, apply the boundary conditions:
                \begin{align}
                    \mathbf{y}^0 = \boldsymbol{\alpha}, 
                    \quad 
                    \mathbf{y}^N = \boldsymbol{\beta},
                    && \left(\text{component units of }\mathbf{y}\right)
                \end{align}
                or, if only some components are known at each boundary, then only those components in $\mathbf{y}^0$ or $\mathbf{y}^N$ are fixed and the remaining must be determined by the system of equations.

            \subsubsection*{Solve the Resulting System of Nonlinear Algebraic Equations}
                Assemble all interior finite-difference approximations (one for each equation at each interior grid point), together with the boundary conditions at $k=0$ and $k=N$, into a large system of algebraic equations. Denoting the unknowns by \(\bigl(\mathbf{y}^1, \mathbf{y}^2, \dots, \mathbf{y}^{N-1}\bigr)\), the total number of unknowns is $7 \times (N-1)$ if all seven state variables are unknown at each interior node (assuming boundary values at $k=0$ and $k=N$ are given). If some boundary values are unknown, then the count of unknowns will adjust accordingly. In any case, the final step is to solve
                \begin{align}
                    \mathcal{R}\Bigl(\mathbf{y}^0,\, \mathbf{y}^1,\, \dots,\, \mathbf{y}^N\Bigr) 
                    = \mathbf{0},
                    && \left(\text{component residual units}\right)
                \end{align}
                where $\mathcal{R}$ denotes the collection of finite-difference equations plus boundary conditions.

            \subsubsection*{Summary}
                By ensuring appropriate grid resolution and an effective nonlinear solver, finite difference approximations can provide accurate, stable solutions to this system of differential equations across the domain $0 \le z \le H$. While this technique can be both robust and straightforward conceptually, it comes with its own potential pitfalls. For instance, a too-coarse grid can lead to poor accuracy or even instability when applied to stiff or highly nonlinear systems. As the mesh becomes finer, the number of equations to be solved grows quickly, which can increase computational cost substantially, especially for higher-dimensional systems. Additionally, nonlinearity may require iterative solvers like Newton's method at each time step or iteration, and assembling and factoring large Jacobians can be computationally intensive. Boundary conditions that are non-standard or mixed in form may also complicate the discretization scheme. Overall, while the finite difference method is a powerful approach, the choice of mesh, solver, and stability considerations must be carefully addressed for each specific problem.

        \subsection{Collocation BVP Method}
            The collocation calculation uses the \texttt{scipy.integrate.solve\_bvp} routine for residual-controlled BVP solution with adaptive mesh refinement. This is the package routine used for the collocation method; it is not a custom orthogonal-collocation code built from user-selected Legendre or Chebyshev points. For reproducibility, each run reports the starting mesh size, maximum node count, solver tolerance, boundary-condition tolerance, initialization profile, scaling, final residual norm, and convergence message.

            \subsubsection*{Mesh and Initial Profile}
                The method starts with an axial mesh over the packed height and an initial profile for every state variable on that mesh. For this absorber model, the profile includes liquid and vapor apparent molar flow rates, liquid and vapor enthalpy flows, and pressure. The starting profile may be constant, linearly interpolated between boundary values, or reused from a nearby operating point. This choice matters because chemical equilibrium, fugacity, enhancement-factor, and transport calculations are all nonlinear functions of the local state. A poor starting profile can push some mesh intervals outside the physical domain; a profile that respects inlet flows, temperatures, and pressure gives the nonlinear solve a better starting point.

            \subsubsection*{Local Polynomial Representation}
                Instead of integrating from one end of the column to the other, collocation represents each state variable with piecewise polynomial functions over the mesh intervals. Within each interval, the polynomial derivative is forced to match the governing-equation residual at selected internal points. The boundary conditions are enforced at the same time. This turns the two-point BVP into one coupled nonlinear algebraic problem over the whole column. The key difference from shooting is that both column ends influence the solution at once, so the method does not depend on guessing one boundary and propagating that guess through the full packed height.

            \subsubsection*{Collocation Equations}
                Let the mesh be $0=z_0<z_1<\cdots<z_N=H$. On interval $[z_j,z_{j+1}]$, the state is approximated by a local polynomial $\mathbf{p}_j(z)$:
                \begin{align}
                    \mathbf{y}(z) &\approx \mathbf{p}_j(z),
                    \qquad z_j \le z \le z_{j+1}
                    && \left(\text{component units of }\mathbf{y}\right).
                \end{align}
                At each collocation point $z_{j,q}$ inside the interval, the polynomial derivative is constrained to match the absorber model:
                \begin{align}
                    \mathbf{p}'_j(z_{j,q})
                    -\mathbf{f}\left(z_{j,q},\mathbf{p}_j(z_{j,q})\right)
                    &= \mathbf{0},
                    \qquad q=1,\ldots,s
                    && \left(\text{component units of }\mathbf{y}\,\unit{m^{-1}}\right).
                \end{align}
                Neighboring interval polynomials must also meet at the mesh nodes,
                \begin{align}
                    \mathbf{p}_{j-1}(z_j)-\mathbf{p}_{j}(z_j)
                    &=\mathbf{0},
                    \qquad j=1,\ldots,N-1
                    && \left(\text{component units of }\mathbf{y}\right),
                \end{align}
                while the boundary conditions close the system:
                \begin{align}
                    \mathbf{B}\left(\mathbf{p}_0(0),\mathbf{p}_{N-1}(H)\right)
                    &= \mathbf{0}
                    && \left(\text{boundary residual units}\right).
                \end{align}
                Collecting the polynomial coefficients and mesh-state values into $\mathbf{U}$ gives the nonlinear algebraic problem solved by the collocation routine:
                \begin{align}
                    \mathbf{R}(\mathbf{U}) &= \mathbf{0}
                    && \left(\text{scaled residual units}\right).
                \end{align}

            \subsubsection*{Nonlinear Iteration and Residual Control}
                The coupled algebraic system is solved iteratively. At each iteration, the model evaluates governing-equation residuals, boundary residuals, and the scaling used to put variables on comparable magnitudes. The solver then updates the mesh-state values until the polynomial profile better satisfies both the differential equations and the boundary conditions. For this absorber model, one residual evaluation is not cheap: each axial point requires chemical-equilibrium, thermodynamic driving-force, transport-property, enhancement-factor, and flux calculations. For that reason, the benchmark records more than a success flag. It reports residual norm, boundary residual, runtime, mesh size, and solver message.

            \subsubsection*{Adaptive Mesh Refinement}
                After a candidate solution is found on the current mesh, the method estimates where the collocation residual is largest. Intervals with larger residuals receive more mesh nodes, and the nonlinear solve is repeated on the refined mesh. This is useful for packed-column absorption because temperature and concentration profiles can be smooth through most of the bed but sharper near a thermal bulge or thermodynamic pinch. A fixed coarse mesh can miss those regions, while a very fine uniform mesh makes every solve larger. Adaptive refinement puts nodes where the solution needs them, within the maximum-node limit reported for the benchmark.

            \subsubsection*{Benchmark Role}
                In this work, collocation is a solver configuration in the benchmark, not a separate methodological contribution. It is the primary method for the NCCC one-bed validation because it handles mixed boundary conditions and localized profile changes better than propagating an initial-value guess through the full column. That does not make it automatically superior. Its performance still depends on scaling, initialization, mesh limits, residual tolerances, and whether the property models stay inside their valid domains. The benchmark output records those settings and reports adaptive mesh behavior, convergence message, boundary residual norm, runtime, and validation error so that any claim about robustness or speed is tied to the actual runs.

        \subsection{Reproducibility and Numerical Settings}
            The benchmark calculations were run in Python 3.13 with fixed package versions. Each result row records the case, method configuration, convergence message, residual information, capture error, temperature error where measured taps are available, runtime, mesh settings, solver tolerances, initialization notes, and thermodynamic model. The full benchmark dataset also retains Python version, platform, and package-version information. The same reporting fields are used for all solver paths, so numerical behavior can be compared directly across methods.

            The thermodynamic benchmark includes the Henry-law baseline and an ePC-SAFT sensitivity model. In the ePC-SAFT calculation, the equation of state supplies the CO$_2$ fugacity coefficients while the same concentration-based chemical-equilibrium calculation remains active for the routine C-case campaign. Only the CO$_2$ fugacity driving force changes in those seven validation runs. Chemical equilibrium, enhancement factor, transport-property correlations, and governing balances are held fixed. Pressure is specified for each ePC-SAFT phase state, and density initialization is used only to speed the numerical solve. The selected ePC-SAFT configuration uses the ionic-fit MEA dataset and the 2025 Figiel-style empirical fitted-Born SSM+DS option set: Debye--Huckel, fitted Born diameters, solvation-shell correction, dielectric saturation, empirical relative permittivity, and numerical Born chemical-potential derivatives. The liquid phase uses those ionic terms directly; the vapor phase uses the same fugacity-coefficient framework with only neutral species present. A separate full ionic speciation test routes ePC-SAFT activity-related quantities into the chemical-equilibrium calculation before evaluating the fugacity driving force. That run is reported as a timing and feasibility boundary, while the repeated C-case campaign uses the faster fugacity-only ePC-SAFT path.
