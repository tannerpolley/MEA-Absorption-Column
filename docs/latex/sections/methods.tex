    \section{Methods}
        For all three numerical methods, the packed-column problem can be written as the boundary value problem
        \begin{align}
            \begin{cases}
            \displaystyle
            \frac{d \mathbf{y}}{dz} = \mathbf{f}\bigl(z, \mathbf{y}(z)\bigr) \\
            \mathbf{y}(0) = \boldsymbol{\alpha}, \quad \mathbf{y}(H) = \boldsymbol{\beta},
            \end{cases}
            &&
            \begin{matrix}
            \left(\text{component units of }\mathbf{y}\,\unit{m^{-1}}\right)\\
            \left(\text{component units of }\mathbf{y}\right)
            \end{matrix}
        \end{align}
        This benchmark compares shooting, finite difference, and collocation on the same packed-absorption-column BVP. Shooting and finite difference expose different initialization and discretization behavior. Collocation is used as the reference method for the reported NCCC rows because it provides adaptive mesh refinement and residual reporting. Method comparisons use recorded runtime, residuals, capture, and unsuccessful-run counts rather than qualitative rankings.

        \subsection{Shooting Method}
            The shooting calculation guesses the unknown inlet-side state values, integrates the absorber balances across the packed height, and adjusts the guess until the outlet-side boundary conditions are met. For a guessed parameter vector $\mathbf{p}$, one integration gives $\mathbf{y}(H;\mathbf{p})$. The boundary mismatch is
                \begin{align}
                    \mathbf{F}(\mathbf{p}) = \mathbf{y}\bigl(H; \mathbf{p}\bigr) - \boldsymbol{\beta}
                    && \left(\text{component units of }\mathbf{y}\right).
                \end{align}
                The root-finding problem is therefore
                \begin{align}
                    \mathbf{F}(\mathbf{p}) &= \mathbf{0}
                    && \left(\text{component units of }\mathbf{y}\right),
                \end{align}
                with each nonlinear iteration requiring another packed-column integration. Shooting returned the shorter recorded runtime for the smooth comparison case, but it did not return an included solution for the NCCC 3C thermal-pinch comparison. It is therefore retained as a numerical-method comparison and is not used for the routine NCCC rows.

        \subsection{Finite Difference}
            The finite-difference calculation replaces the continuous axial derivatives with mesh-based algebraic residuals. The packed height is divided into $N$ intervals with
                \begin{align}
                    z_k = k\,\Delta z, \quad k = 0, 1, 2, \ldots, N,
                    && \left(\unit{m}\right)
                \end{align}
                where $\Delta z=H/N$. The nodal state $\mathbf{y}^k$ approximates the absorber state at $z_k$,
                \begin{align}
                    \mathbf{y}^k \;\approx\; \mathbf{y}\bigl(z_k\bigr)
                    && \left(\text{component units of }\mathbf{y}\right).
                \end{align}
                Interior derivatives are represented with central differences,
                \begin{align}
                    \frac{d \mathbf{y}}{dz}\biggr\rvert_{z=z_k}
                    \approx
                    \frac{\mathbf{y}^{k+1} - \mathbf{y}^{k-1}}{2\,\Delta z},
                    \quad 
                    k = 1, 2, \ldots, N-1
                    && \left(\text{component units of }\mathbf{y}\,\unit{m^{-1}}\right).
                \end{align}
                The boundary nodes enforce the inlet and outlet conditions,
                \begin{align}
                    \mathbf{y}^0 = \boldsymbol{\alpha}, 
                    \quad 
                    \mathbf{y}^N = \boldsymbol{\beta},
                    && \left(\text{component units of }\mathbf{y}\right)
                \end{align}
                for the components fixed by the mixed column boundary specification. Collecting the finite-difference equations and boundary equations gives
                \begin{align}
                    \mathcal{R}\Bigl(\mathbf{y}^0,\, \mathbf{y}^1,\, \dots,\, \mathbf{y}^N\Bigr) 
                    = \mathbf{0},
                    && \left(\text{component residual units}\right)
                \end{align}
                over all nodal unknowns. Finite difference gives a direct algebraic discretization check against shooting and collocation. In this absorber problem, however, an algebraic solve can return a low boundary residual on a branch whose predicted capture lies outside the physical range or far from the measured value. The finite-difference rows are therefore interpreted through capture, temperature, and residual evidence rather than by the solver report alone.

        \subsection{Collocation BVP Method}
            The collocation calculation uses an adaptive residual-controlled BVP routine. It is not a custom orthogonal-collocation code built from user-selected Legendre or Chebyshev points. Each retained row reports the starting mesh size, maximum node count, solver tolerance, boundary-condition tolerance, initialization profile, scaling, final residual norm, and solver message.

            \subsubsection*{Solver Configuration and Initialization}
                The method starts with an axial mesh over the packed height and an initial profile for every state variable on that mesh. For this absorber model, the profile includes liquid and vapor apparent molar flow rates, liquid and vapor enthalpy flows, and pressure. The starting profile may be constant, linearly interpolated between boundary values, or reused from a nearby operating point. This choice matters because chemical equilibrium, fugacity, enhancement-factor, and transport calculations are all nonlinear functions of the local state. A poor starting profile can push some mesh intervals outside the physical domain; a profile that respects inlet flows, temperatures, and pressure gives the nonlinear solve a better starting point.

            \subsubsection*{Collocation Formulation}
                Instead of integrating from one end of the column to the other, collocation represents each state variable with piecewise polynomial functions over the mesh intervals. Within each interval, the polynomial derivative is forced to match the governing-equation residual at selected internal points. The boundary conditions are enforced at the same time. This turns the two-point BVP into one coupled nonlinear algebraic problem over the whole column. The key difference from shooting is that both column ends influence the solution at once, so the method does not depend on guessing one boundary and propagating that guess through the full packed height.

                Let the mesh be $0=z_0<z_1<\cdots<z_N=H$. On interval $[z_j,z_{j+1}]$, the state is approximated by a local polynomial $\mathbf{p}_j(z)$:
                \begin{align}
                    \mathbf{y}(z) &\approx \mathbf{p}_j(z),
                    \qquad z_j \le z \le z_{j+1}
                    && \left(\text{component units of }\mathbf{y}\right).
                \end{align}
                At each collocation point $z_{j,q}$ inside the interval, the polynomial derivative is constrained to match the absorber model:
                \begin{align}
                    \mathbf{p}'_j(z_{j,q})
                    -\mathbf{f}\left(z_{j,q},\mathbf{p}_j(z_{j,q})\right)
                    &= \mathbf{0},
                    \qquad q=1,\ldots,s
                    && \left(\text{component units of }\mathbf{y}\,\unit{m^{-1}}\right).
                \end{align}
                Neighboring interval polynomials must also meet at the mesh nodes,
                \begin{align}
                    \mathbf{p}_{j-1}(z_j)-\mathbf{p}_{j}(z_j)
                    &=\mathbf{0},
                    \qquad j=1,\ldots,N-1
                    && \left(\text{component units of }\mathbf{y}\right),
                \end{align}
                while the boundary conditions close the system:
                \begin{align}
                    \mathbf{B}\left(\mathbf{p}_0(0),\mathbf{p}_{N-1}(H)\right)
                    &= \mathbf{0}
                    && \left(\text{boundary residual units}\right).
                \end{align}
                Collecting the polynomial coefficients and mesh-state values into $\mathbf{U}$ gives the nonlinear algebraic problem solved by the collocation routine:
                \begin{align}
                    \mathbf{R}(\mathbf{U}) &= \mathbf{0}
                    && \left(\text{scaled residual units}\right).
                \end{align}

            \subsubsection*{Nonlinear Solve and Mesh Refinement}
                The coupled algebraic system is solved iteratively. At each iteration, the model evaluates governing-equation residuals, boundary residuals, and the scaling used to put variables on comparable magnitudes. The solver then updates the mesh-state values until the polynomial profile better satisfies both the differential equations and the boundary conditions. Each residual evaluation includes chemical-equilibrium, thermodynamic driving-force, transport-property, enhancement-factor, and flux calculations at every axial point. The retained records therefore include residual norm, boundary residual, runtime, mesh size, and solver message.

                After a candidate solution is found on the current mesh, the method estimates where the collocation residual is largest. Intervals with larger residuals receive more mesh nodes, and the nonlinear solve is repeated on the refined mesh. This is useful for packed-column absorption because temperature and concentration profiles can be smooth through most of the bed but sharper near a thermal bulge or thermodynamic pinch. A fixed coarse mesh can miss those regions, while a very fine uniform mesh makes every solve larger. Adaptive refinement puts nodes where the solution needs them, within the maximum-node limit reported for the benchmark.

            \subsubsection*{Benchmark Role and Reported Diagnostics}
                In this work, collocation is a specified solver choice, not a separate methodological contribution. It is the primary method for the NCCC one-bed comparisons because it enforces mixed boundary conditions while refining localized profile changes. Its numerical results depend on scaling, initialization, mesh limits, residual tolerances, and the validity domains of the property correlations. The retained result rows record the configured starting mesh and maximum-node limit, solver message, boundary-residual norm, runtime, and physical-comparison error. They do not retain the final adaptive node count, refinement history, or method-specific iteration and evaluation counts. The numerical comparison is limited to the recorded diagnostics.

        \subsection{Recorded Numerical Settings}
            The benchmark calculations were run in Python 3.13 with fixed package versions. Each result row records the case, method setting, convergence message, residual information, capture error, temperature error where measured taps are available, runtime, mesh settings, solver tolerances, initialization notes, and thermodynamic model. The full benchmark data record also retains Python version, platform, and package-version information. These common fields support a descriptive comparison across methods. The archived rows do not identify the processor, memory, BLAS thread settings, or system load, so the runtime values should not be interpreted as a controlled hardware benchmark. A stricter computational-cost comparison would require one documented machine and method-specific iteration, evaluation, final-mesh, CPU-time, and memory records.

            The one-bed NCCC rows included in the aggregate use the collocation BVP calculation with 21 starting mesh points, a solver tolerance of 0.5, a boundary-condition tolerance of 0.001, and a maximum of 1000 mesh nodes. The calculation scales flow and enthalpy states, uses bounded state transforms to keep property calls inside their physical domains, and applies the ePC-SAFT CO$_2$ fugacity correction in the ePC-SAFT rows. These settings apply to K18, K19, and 1C--7C. K20 was attempted with the same bounded-state formulation, but neither thermodynamic row satisfied all row-inclusion criteria.

            The thermodynamic benchmark includes the Henry-law reference closure and the ePC-SAFT driving-force calculation. In the ePC-SAFT calculation, the equation of state supplies the CO$_2$ fugacity coefficients while the same concentration-based chemical-equilibrium calculation remains active for the routine one-bed NCCC campaign. Only the CO$_2$ fugacity driving force changes in the included rows. Chemical equilibrium, enhancement factor, transport-property correlations, and governing balances are held fixed. Pressure is specified for each ePC-SAFT phase state. The calculation constructs an immutable parameter document and calls the public \texttt{Parameters--Mixture--State} API in \texttt{epcsaft} 0.2; Helmholtz-energy derivatives are evaluated by CppAD automatic differentiation. The retained benchmark rows use the explicitly recorded \texttt{MEA\_CO2\_H2O\_ionic\_fit} dataset; its parameter summary is given in Appendix~\ref{sec:appendix-properties}. The liquid phase uses the ionic terms directly, whereas the vapor phase contains only neutral species. A separate nine-species diagnostic uses the vendored \texttt{MEA\_reactive\_epcsaft\_bundle} with typed homogeneous equilibrium and exact composition tangents. It is a formulation and stiffness check, not a replacement for the recorded benchmark dataset or an independently validated reactive-thermodynamic model. The activity-rebased column calculation remains excluded from the routine aggregate.

        \subsection{Row-Inclusion Criteria and Reported Metrics}
            A row is included in the routine aggregate only when the selected solver reports success, the boundary-residual norm is at most 1.0, the predicted capture is between 0 and 100\%, and the run finishes within \SI{90}{s}. Temperature root-mean-square error (RMSE), guard count, and invalid-state count are reported but are not row-inclusion criteria. Runs that do not satisfy all four criteria are retained in the attempted-case accounting but are not included in aggregate capture-error or runtime statistics.

            Capture error is reported in percentage points relative to the measured pilot-plant capture. Temperature-profile error is reported only for cases with measured axial temperature taps. Runtime is the wall-clock duration recorded for the model calculation, not an external manual timing. Domain-guard and invalid-state counts identify solver iterations that left the physically valid property domain during an attempted solve. K19 is included because both thermodynamic rows satisfy the solver-success, boundary-residual, physical-capture, and \SI{90}{s} criteria even though the ePC-SAFT and Henry-law rows record 166 and 183 guard events, respectively.
