    \section{Results}
        The results are organized around one question at a time. The NCCC one-bed cases test whether the absorber model gives a coherent validation response across two no-intercooler pilot-plant campaigns. The thermodynamic comparison then changes only the CO$_2$ fugacity driving force. The solver comparison isolates numerical behavior, and the final timing test shows why the full activity-coupled speciation loop is treated as a validated future path rather than the routine campaign model.

    \subsection{NCCC One-Bed Validation}
        The model is benchmarked against one-bed, no-intercooler NCCC MEA absorber runs from the 2014 K campaign and the 2017 C campaign \cite{Morgan2020}. The evaluated operating points are listed in Table~\ref{tab:nccc-one-bed-scope}. The 2017 source table leaves the lean inlet temperature blank for 1C--3C; those three model-input rows use \SI{45.0}{\degreeCelsius}, which is consistent with the tight lean-inlet temperature range in the same campaign.

    \subsection{ePC-SAFT Driving-Force Comparison}
        The Henry-law baseline uses a liquid Henry-law CO$_2$ fugacity and an ideal vapor partial-pressure expression. The ePC-SAFT calculation replaces that closure with vapor- and liquid-side fugacity coefficients computed from pressure-specified phase states. The liquid phase uses the ePC-SAFT electrolyte configuration described in Section~\ref{sec:model-framework}. The vapor-side calculation uses the same fugacity-coefficient framework with only neutral species present.

        \begin{figure}
            \centering
            \includegraphics[width=0.92\textwidth]{figures/nccc-one-bed-thermo-benchmark.pdf}
            \caption{Thermodynamic driving-force comparison for accepted one-bed, no-intercooler NCCC cases from the 2014 K and 2017 C campaigns. The left panel reports case-by-case capture error, and the right panel reports median runtime for accepted rows.}
            \label{fig:nccc-one-bed-thermo-benchmark}
        \end{figure}

        Figure~\ref{fig:nccc-one-bed-thermo-benchmark} is the main thermodynamic comparison. Across the accepted one-bed rows, ePC-SAFT gives a capture mean absolute error of 3.73 percentage points, compared with 3.78 percentage points for Henry-law closure. Its median runtime is \SI{9.86}{s}, compared with \SI{8.62}{s} for Henry-law closure. That runtime increase is small compared with the added thermodynamic structure: ePC-SAFT evaluates vapor- and liquid-side fugacity coefficients instead of using the idealized driving-force closure, while remaining fast enough for repeated benchmark runs.

    \subsection{Numerical Solver Behavior}
        The solver comparison answers a different question than the thermodynamic comparison. It tests how shooting, collocation, and finite difference behave when they are applied to the same absorber equations under representative operating conditions. The SRP-style case is smoother and favorable to all three methods. The NCCC 3C case is more demanding because the measured profile contains a sharper temperature feature.

Shooting is efficient on the favorable SRP-style point, but it does not meet the NCCC 3C acceptance gate. Finite difference is informative as an algebraic discretization check, but its favorable-case capture value shows that convergence alone is not the same as physical validation. Collocation gives the most reliable accepted result for the NCCC 3C thermal-pinch case while still reporting the mesh, residual, and runtime information needed for reproduction.

    \subsection{Full Ionic Speciation Timing Test}
        The routine one-bed campaign keeps the concentration-based chemical-equilibrium calculation fixed and uses ePC-SAFT for the CO$_2$ fugacity coefficients. A separate full ionic activity-speciation test was run to check the stronger path: ePC-SAFT activity-related quantities enter the chemical-equilibrium calculation, and the resulting true-species state then feeds the ionic liquid fugacity calculation. The clean proof run, implemented as \code{epcsaft\_reactive\_six\_activity\_rebased}, converges for Case 3C with no domain guards and chemistry residuals near $10^{-8}$.

        \input{tables/full_ionic_speciation_timing}

        Table~\ref{tab:full-ionic-speciation-timing} gives the practical reason this full loop is not used for every routine validation row. The activity-coupled Case 3C proof run predicts $\SI{89.837}{\percent}$ capture, only 0.337 percentage points from the measured value, but it takes \SI{129.282}{s}; \SI{90.629}{s} of that runtime is spent in the ePC-SAFT chemistry solves. This makes the full ionic activity-speciation loop a clear feasibility result and a concrete acceleration target. For repeated one-bed simulations, the faster ePC-SAFT fugacity calculation is the right middle ground: it brings the ionic EOS into the absorber driving force while preserving the speed needed for solver and thermodynamic benchmarking.

    \subsection{Limitations and Future Work}
        The scope limits are collected here rather than repeated throughout the results. The absorber model is a simplified one-bed benchmark built from literature submodels for reaction enhancement, transport properties, hydraulics, and heat transfer. The primary validation set is the accepted one-bed NCCC case set from the 2014 K and 2017 C campaigns, so broader claims about multi-bed operation, plantwide optimization, or other solvents require additional data. The routine ePC-SAFT campaign changes the CO$_2$ fugacity driving force while holding the concentration-based chemistry, enhancement factor, transport correlations, and governing balances fixed. The full activity-coupled ePC-SAFT speciation loop has now been shown to converge for Case 3C, but it is still too slow for the repeated-run role of this paper. Future work should focus on making that loop practical through caching, tabulation, continuation, or refitting activity-basis constants, and then validating it across the same campaign set. Direct eNRTL comparisons should likewise be added only when the calibration choices and timing data are reported on the same basis as the present benchmark.
