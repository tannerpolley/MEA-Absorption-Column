    \section{Results}
        This section presents the implementation and evaluation of the MEA absorption column model. The results are organized around reproducible benchmark evidence instead of a single illustrative simulation. The primary validation tier uses the one-bed NCCC C cases because temperature-profile data are available for those runs. The thermodynamic comparison is reported separately so that the effect of replacing only the CO$_2$ fugacity driving force can be interpreted without changing the reaction or transport submodels at the same time.

        \subsection{Benchmark Implementation}
    
            To evaluate these methods, a modular steady-state absorber implementation was used to simulate amine-based absorption columns for CO\textsubscript{2} capture using pilot-plant cases from the National Carbon Capture Center (NCCC). The framework accommodates shooting, finite-difference, and collocation BVP solution paths within a single governing-equation set. The reported solver and thermodynamic comparison tables are regenerated from fixed input data and preserve the full run history so that solver messages, residual norms, mesh settings, thermodynamic model identifiers, and case metadata remain traceable to the computational configuration.

The Henry-law and neutral ePC-SAFT lanes both converged for all seven cases and kept absolute capture error below ten percentage points. Their aggregate capture errors were similar, with mean absolute capture errors of 4.70 percentage points for Henry-law closure and 4.66 percentage points for neutral ePC-SAFT. The neutral ePC-SAFT lane required a longer median runtime because the vapor- and liquid-side fugacity coefficients are computed through the ePC-SAFT equation-of-state package, but the median runtime remained \SI{14.81}{s} compared with \SI{12.21}{s} for Henry-law closure. This supports its use as a middle-ground thermodynamic option when the Henry-law closure is considered too idealized but a fully activity-coefficient or electrolyte-reactive recalibration would be too costly or over-parameterized for the intended benchmark.

    \subsection{Simulation Method Comparison}
        Figure~\ref{fig:method_comparison_figures} illustrates the temperature profiles obtained using three numerical methods: shooting, collocation, and finite difference. At higher $L/G$ ratios, the temperature bulge shifts toward the bottom of the column, which generally results in well-conditioned differential equations that the shooting method can solve efficiently. When the bulge appears near the top of the column (commonly associated with thermodynamic pinch points), the shooting path becomes less robust because of the stiffness and sensitivity of the coupled ODEs. The shooting path can also be run with stiff IVP integrators for comparison, but those runs require explicit runtime limits because poor boundary guesses can otherwise generate long root-search trajectories.

        The collocation method provides an adaptive boundary-value alternative for the same governing equations. Its performance depends on the initialization profile, scaling, mesh limits, and tolerance settings, so the benchmark reports those values directly rather than treating robustness as a qualitative observation.

        The finite difference method offers another solution strategy by solving the spatially discretized equations as one nonlinear algebraic system. Its usefulness must be evaluated from the same metrics as the other methods: convergence success, boundary residuals, validation error, mesh size, and runtime.

        Each method has trade-offs. The shooting method is simple but can be sensitive to stiffness; the collocation method depends strongly on initialization and mesh controls; and finite difference methods increase the nonlinear system size. Table~\ref{tab:method_comparison_table} should be interpreted alongside the quantitative benchmark outputs.

        The benchmark replaces qualitative method rankings with reported statistics. A defensible comparison reports convergence behavior, boundary residuals, validation errors, and runtime across representative cases. On the current evidence, the collocation path is the reference workflow for the NCCC one-bed validation because it handles the thermal-pinch case more reliably than the shooting and finite-difference paths. Shooting and finite difference remain useful comparison paths for favorable SRP-style one-bed cases because they expose speed, stiffness, initialization, and nonlinear-system conditioning tradeoffs.


    \subsection{Limitations and Future Work}
        The results should be read as a reproducible benchmark of a simplified absorber model, not as a complete predictive process simulator. The ePC-SAFT lanes are limited to the CO$_2$ fugacity-coefficient driving force; they do not replace the chemical-equilibrium model, ionic speciation calculation, reaction-enhancement calculation, or transport-property correlations with a fully coupled electrolyte-reactive thermodynamic model. The one-bed NCCC C cases provide the primary validation set with measured temperature taps, and the benchmark remains most valuable as a documented basis for solver comparison and thermodynamic sensitivity. Future absorption-column studies that need a balance between accuracy and speed can use this style of ePC-SAFT fugacity lane as an intermediate thermodynamic choice, while reserving fully audited electrolyte ePC-SAFT or eNRTL \cite{Zhang2011} comparisons for work where the additional calibration and runtime cost are justified. Optimization and scale-up studies should remain future applications unless supported by validation data.
