    \section{Results}
        The results are organized around one question at a time. The NCCC C cases test whether the absorber model gives a coherent validation response across the available one-bed campaign. The thermodynamic comparison then changes only the CO$_2$ fugacity driving force. The solver comparison isolates numerical behavior, and the final timing test shows why the full activity-coupled speciation loop is treated as a validated future path rather than the routine campaign model.

    \subsection{ePC-SAFT Driving-Force Comparison}
        The Henry-law baseline uses a liquid Henry-law CO$_2$ fugacity and an ideal vapor partial-pressure expression. The ePC-SAFT calculation replaces that closure with vapor- and liquid-side fugacity coefficients computed from pressure-specified phase states. The liquid phase uses the ionic-fit MEA dataset with Debye--Huckel, fitted Born diameters, SSM, DS, empirical dielectric mixing, and numerical Born chemical-potential derivatives. The vapor-side calculation uses the same fugacity-coefficient framework with only neutral species present.

        \begin{figure}
            \centering
            \includegraphics[width=0.92\textwidth]{figures/c-case-thermo-benchmark.pdf}
            \caption{Thermodynamic driving-force comparison for the corrected one-bed NCCC C cases. Both calculations converge for all seven cases; the left panel reports case-by-case capture error and the right panel reports median runtime.}
            \label{fig:c-case-thermo-benchmark}
        \end{figure}

        Figure~\ref{fig:c-case-thermo-benchmark} is the main thermodynamic comparison. Both calculations converge for all seven C cases. The ePC-SAFT calculation gives a modestly lower capture mean absolute error, 4.54 percentage points compared with 4.70 percentage points for Henry-law closure. Its median runtime is \SI{18.93}{s}, compared with \SI{13.93}{s} for Henry-law closure. That runtime increase is expected because ePC-SAFT evaluates vapor- and liquid-side fugacity coefficients and the liquid-side ionic contribution terms. The important point is that the calculation remains fast enough for repeated benchmark runs while replacing the idealized driving-force closure with a more structured electrolyte equation-of-state calculation.

    \subsection{Numerical Solver Behavior}
        The solver comparison answers a different question than the thermodynamic comparison. It tests how shooting, collocation, and finite difference behave when they are applied to the same absorber equations under representative operating conditions. The SRP-style case is smoother and favorable to all three methods. The NCCC 3C case is more demanding because the measured profile contains a sharper temperature feature.

Shooting is efficient on the favorable SRP-style point, but it does not meet the NCCC 3C acceptance gate. Finite difference is informative as an algebraic discretization check, but its favorable-case capture value shows that convergence alone is not the same as physical validation. Collocation gives the most reliable accepted result for the NCCC 3C thermal-pinch case while still reporting the mesh, residual, and runtime information needed for reproduction.

    \subsection{Full Ionic Speciation Timing Test}
        The routine C-case campaign keeps the concentration-based chemical-equilibrium calculation fixed and uses ePC-SAFT for the CO$_2$ fugacity coefficients. A separate full ionic activity-speciation test was run to check the stronger path: ePC-SAFT activity-related quantities enter the chemical-equilibrium calculation, and the resulting true-species state then feeds the ionic liquid fugacity calculation. The clean proof run, implemented as \code{epcsaft\_reactive\_six\_activity\_rebased}, converges for Case 3C with no domain guards and chemistry residuals near $10^{-8}$.

        \input{tables/full_ionic_speciation_timing}

        Table~\ref{tab:full-ionic-speciation-timing} gives the practical reason this full loop is not used for every routine validation row. The activity-coupled Case 3C proof run predicts $\SI{89.837}{\percent}$ capture, only 0.337 percentage points from the measured value, but it takes \SI{129.282}{s}; \SI{90.629}{s} of that runtime is spent in the ePC-SAFT chemistry solves. This makes the full ionic activity-speciation loop a clear feasibility result and a concrete acceleration target. For repeated C-case simulations, the faster ePC-SAFT fugacity calculation is the right middle ground: it brings the ionic EOS into the absorber driving force while preserving the speed needed for solver and thermodynamic benchmarking.

    \subsection{Limitations and Future Work}
        The scope limits are collected here rather than repeated throughout the results. The absorber model is a simplified one-bed benchmark built from literature submodels for reaction enhancement, transport properties, hydraulics, and heat transfer. The primary validation set is the corrected NCCC C-case campaign, so broader claims about scale-up, plantwide optimization, or other solvents require additional data. The routine ePC-SAFT campaign changes the CO$_2$ fugacity driving force while holding the concentration-based chemistry, enhancement factor, transport correlations, and governing balances fixed. The full activity-coupled ePC-SAFT speciation loop has now been shown to converge for Case 3C, but it is still too slow for the repeated-run role of this paper. Future work should focus on making that loop practical through caching, tabulation, continuation, or refitting activity-basis constants, and then validating it across the same campaign set. Direct eNRTL comparisons should likewise be added only when the calibration choices and timing data are reported on the same basis as the present benchmark.
