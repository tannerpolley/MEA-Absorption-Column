    \section{Results}
        The results are organized around one question at a time. The NCCC one-bed cases test whether the absorber model gives a coherent validation response across two no-intercooler pilot-plant campaigns. The thermodynamic comparison then changes only the CO$_2$ fugacity driving force. The solver comparison isolates numerical behavior, and the final timing test shows why the full activity-coupled speciation loop is feasible but still too slow for the routine campaign model.

    \subsection{NCCC One-Bed Validation}

    \subsection{ePC-SAFT Driving-Force Comparison}
        The Henry-law baseline uses a liquid Henry-law CO$_2$ fugacity and an ideal vapor partial-pressure expression. The ePC-SAFT calculation replaces that closure with vapor- and liquid-side fugacity coefficients computed from pressure-specified phase states. The liquid phase uses the ePC-SAFT electrolyte configuration described in Section~\ref{sec:model-framework}. The vapor-side calculation uses the same fugacity-coefficient framework with only neutral species present.

        \begin{center}
            \centering
            \includegraphics[width=0.92\textwidth]{figures/nccc-one-bed-thermo-benchmark.pdf}
            \captionof{figure}{Thermodynamic driving-force comparison for accepted one-bed, no-intercooler NCCC cases from the 2014 K and 2017 C campaigns. The left panel reports case-by-case capture error, and the right panel reports median runtime for accepted rows. K20 and 7C are excluded because they did not satisfy the common accepted-row gate.}
            \label{fig:nccc-one-bed-thermo-benchmark}
        \end{center}

        Figure~\ref{fig:nccc-one-bed-thermo-benchmark} is the main thermodynamic comparison. Across the accepted one-bed rows, ePC-SAFT gives a capture mean absolute error of 2.89 percentage points, compared with 2.74 percentage points for Henry-law closure. Its median runtime is \SI{7.57}{s}, compared with \SI{5.24}{s} for Henry-law closure. This aggregate does not show a lower capture-error result for ePC-SAFT; it shows a comparable prediction while replacing the idealized driving-force closure with vapor- and liquid-side fugacity coefficients. The runtime increase remains small enough for repeated benchmark runs.

    \subsection{Numerical Solver Behavior}
        The solver comparison answers a different question than the thermodynamic comparison. It tests how shooting, collocation, and finite difference behave when they are applied to the same absorber equations under representative operating conditions. A smooth one-bed operating point is favorable to all three methods. The NCCC 3C case is more demanding because the measured profile contains a sharper temperature feature.

        \input{tables/method_case_contrast}

        \begin{center}
            \centering
            \includegraphics[width=0.78\textwidth]{figures/method-case-solver-contrast.pdf}
            \captionof{figure}{Runtime and method comparison for representative one-bed cases. The smooth operating point demonstrates that shooting can be fast on favorable profiles; the NCCC 3C case identifies collocation BVP solution as the reference method for measured temperature-profile validation. The y-axis is linear.}
            \label{fig:method-case-solver-contrast}

        Table~\ref{tab:method-case-contrast} and Figure~\ref{fig:method-case-solver-contrast} show why collocation is used as the reference method for the NCCC validation rows. Shooting is efficient on the smoother point, but it does not meet the NCCC 3C acceptance gate. A separate high-liquid-to-gas-ratio probe supports the favorable-case side of this result: shooting solved 20 of 25 explicit-vapor-water rows with a median model runtime of \SI{0.78}{s}, and it solved 25 of 25 rows under the older vapor-water-ratio assumption with a median model runtime of \SI{0.85}{s}. That evidence is used only as a speed and conditioning check, not as primary validation. Finite difference is informative as an algebraic discretization check, but its favorable-case capture value shows that convergence alone is not the same as physical validation. Collocation gives the most reliable accepted result for the NCCC 3C thermal-pinch case while still reporting the mesh, residual, and runtime information needed for reproduction.

    \subsection{Full Ionic Speciation Timing Test}
        The routine one-bed campaign keeps the concentration-based chemical-equilibrium calculation fixed and uses ePC-SAFT for the CO$_2$ fugacity coefficients. A separate full ionic activity-speciation sweep was run to check the stronger path: ePC-SAFT activity-related quantities enter the chemical-equilibrium calculation, and the resulting true-species state then feeds the ionic liquid fugacity calculation. The sweep uses a nine-species ionic state for CO$_2$, MEA, H$_2$O, MEAH$^+$, MEACOO$^-$, HCO$_3^-$, $\mathrm{CO_3^{2-}}$, $\mathrm{H_3O^+}$, and $\mathrm{OH^-}$. It converged for all seven 2017 C-case rows with no invalid states, no domain guards, and chemistry residuals below $10^{-8}$.

        \input{tables/full_ionic_speciation_timing}

Table~\ref{tab:full-ionic-speciation-timing} gives the practical reason this full loop is not used for every routine validation row. The full activity-coupled sweep uses relaxed feasibility settings: 7 starting mesh points, a solver tolerance of 10, a boundary-condition tolerance of 0.5, and a maximum of 80 mesh nodes. The nine-species Case 3C row predicts $\SI{88.736}{\percent}$ capture, $-0.764$ percentage points from the measured value, but it takes \SI{139.420}{s}; \SI{102.267}{s} of that runtime is spent in the ePC-SAFT chemistry solves. Across all seven C rows, the mean runtime is \SI{171.102}{s}, the mean chemistry-solve time is \SI{127.764}{s}, and the capture mean absolute error is 6.595 percentage points. These results establish the full ionic activity-speciation loop as a feasible but slow path and a concrete acceleration target, not as the routine validation model used for the main thermodynamic comparison.

    \subsection{Limitations and Future Work}
        The scope limits are collected here rather than repeated throughout the results. The absorber model is a simplified one-bed benchmark built from literature submodels for reaction enhancement, transport properties, hydraulics, and heat transfer. The primary validation set is the accepted one-bed NCCC case set from the 2014 K and 2017 C campaigns, so broader claims about multi-bed operation, plantwide optimization, or other solvents require additional data. Attempted two-bed 2017 D cases and higher-height cases did not meet the common bounded solver gate in the present evidence set, so they are not used as validation evidence. The routine ePC-SAFT campaign changes the CO$_2$ fugacity driving force while holding the concentration-based chemistry, enhancement factor, transport correlations, and governing balances fixed. The full activity-coupled ePC-SAFT speciation loop has now been shown to converge across the seven 2017 C rows, but it is still too slow for the repeated-run role of this paper and its capture accuracy is uneven across the full C set. Future work should focus on making that loop practical through caching, tabulation, continuation, or refitting activity-basis constants, and then validating it across the same campaign set. Direct eNRTL comparisons should likewise be added only when the calibration choices and timing data are reported on the same basis as the present benchmark.
