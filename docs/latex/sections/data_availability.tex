The MEA-only manuscript and evidence state preserved before MDEA companion work is available at the \href{https://github.com/tannerpolley/MEA-Absorption-Column/tree/nce-mea-only-pre-mdea-2026-08-25}{MEA-only pre-MDEA freeze tag dated 2026-08-25}. No archival DOI has been minted for this repository at the time of manuscript preparation; the cited GitHub tag should be used for reproduction until an archive is issued.
