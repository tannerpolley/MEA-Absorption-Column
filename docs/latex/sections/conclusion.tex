    \section{Conclusion}
        This work uses a simplified MEA absorber model to benchmark numerical solution methods and thermodynamic driving-force assumptions under a fixed set of governing equations. The evidence extends beyond a single illustrative validation case by adding one-bed NCCC metrics, attempted-case accounting, solver information, boundary residuals, temperature-profile evidence, method contrasts, and ePC-SAFT fugacity-coefficient comparisons. To the authors' knowledge, the ePC-SAFT contribution is the first absorber-column benchmark in which a liquid-side ionic ePC-SAFT CO$_2$ fugacity calculation is evaluated inside the thermodynamic driving force while concentration-based chemical equilibrium, enhancement, transport, hydraulics, and balances remain fixed. The vapor-side fugacity is evaluated with the same framework in its neutral limit.

        Both thermodynamic calculations converged for the accepted one-bed validation rows and stayed near the measured capture values. ePC-SAFT gave a capture mean absolute error of 3.73 percentage points, compared with 3.78 percentage points for Henry-law closure, while median runtime increased from \SI{8.62}{s} to \SI{9.86}{s}. The separate nine-species activity-coupled ePC-SAFT speciation sweep also converged for all seven 2017 C rows with chemistry residuals below $10^{-8}$, zero invalid states, and zero guard penalties, but its capture accuracy was uneven and its mean runtime was \SI{171.102}{s}. That result identifies the activity-coupled loop as a feasible acceleration target rather than the routine validation model for this benchmark. Overall, the results support ePC-SAFT as a practical CO$_2$ fugacity-closure option when the goal is an electrolyte equation-of-state driving force at repeated-run cost. The solver comparison also shows how method choice changes runtime and conditioning under the same governing equations. The central conclusion is that shared benchmark data, explicit solver settings, residuals, and runtime reporting provide a stronger basis for evaluating this class of absorber model than a single successful case study.
