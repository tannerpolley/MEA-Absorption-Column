    \section{Conclusion}
        This work uses a simplified MEA absorber model to benchmark numerical solution methods and thermodynamic driving-force assumptions. The evidence extends beyond a single illustrative validation case by adding one-bed NCCC metrics, solver information, boundary residuals, temperature-profile evidence, method contrasts, and ePC-SAFT fugacity-coefficient comparisons. To the authors' knowledge, the ePC-SAFT contribution is the first absorber-column benchmark in which a full ionic liquid-side ePC-SAFT fugacity calculation is evaluated inside the CO$_2$ thermodynamic driving force. The vapor-side fugacity is evaluated with the same framework in its neutral limit.

        Both thermodynamic calculations converged for the accepted one-bed validation rows and stayed near the measured capture values. ePC-SAFT reduced capture MAE relative to the Henry-law calculation, while median runtime increased from about 9 to 10 seconds. The full nine-species activity-coupled ePC-SAFT speciation sweep also converged for all seven 2017 C rows with chemistry residuals below $10^{-8}$, zero invalid states, and zero guard penalties. Its mean runtime of \SI{171.102}{s} still shows why it is better treated as the next accelerated path rather than the routine model for this benchmark. Together, these results make ePC-SAFT a useful middle-ground option for future absorption-column simulation studies that need more thermodynamic structure than idealized Henry-law closure while still preserving practical runtime. The method contrast also shows how solver choice changes runtime and conditioning under the same governing equations, including a fast shooting result on smoother SRP-like rows. The central conclusion is that shared benchmark data, explicit solver settings, residuals, and runtime reporting provide a stronger basis for evaluating this class of absorber model than a single successful case study.
