    \section{Conclusion}
        This work presents a transparent Python framework for benchmarking a simplified MEA absorber model, numerical solution methods, and thermodynamic driving-force assumptions. The evidence extends beyond a single illustrative validation case by adding one-bed C-case metrics, solver metadata, boundary-residual metadata, temperature-profile evidence, SRP-style method-contrast evidence, and ePC-SAFT fugacity-coefficient sensitivity lanes. To the authors' knowledge, the ePC-SAFT contribution is the first absorber-column benchmark in which package-based ePC-SAFT fugacity coefficients are evaluated on both the vapor and liquid sides of the CO$_2$ thermodynamic driving force. These additions make the contribution defensible as a reproducible benchmark rather than as a new high-fidelity absorber model.

        The results also define the limits of the current model. The Henry-law lane remains the fastest validation path, while the ePC-SAFT lanes demonstrate how the same model can be run with EOS-based CO$_2$ fugacity driving forces at higher but still practical computational cost while keeping the legacy chemistry fixed. This makes the ePC-SAFT lane a recommended middle-ground option for future absorption-column simulation studies that need more thermodynamic structure than idealized Henry-law closure but do not yet require a fully calibrated activity-coefficient or electrolyte-reactive workflow. The SRP/NCCC method contrast also shows how solver choice changes runtime and conditioning under the same governing equations. The paper's central conclusion is that transparent benchmark datasets, explicit solver settings, residuals, and runtime reporting provide a stronger and more reproducible basis for evaluating this class of absorber model than a single successful case study.
