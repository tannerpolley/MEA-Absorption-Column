    \section{Conclusion}
        This work uses a simplified MEA absorber model to benchmark numerical solution methods and thermodynamic driving-force assumptions. The evidence extends beyond a single illustrative validation case by adding one-bed C-case metrics, solver information, boundary residuals, temperature-profile evidence, SRP-style method contrasts, and PC-SAFT fugacity-coefficient sensitivity calculations. To the authors' knowledge, the PC-SAFT contribution is the first absorber-column benchmark in which package-based PC-SAFT fugacity coefficients are evaluated on both the vapor and liquid sides of the CO$_2$ thermodynamic driving force. The result is a reproducible benchmark, not a new high-fidelity absorber model.

        The campaign-input C-case results also define the practical limits of the current model without turning the contribution into a list of caveats. Both thermodynamic calculations converged for all seven one-bed C cases and stayed below ten percentage points of absolute capture error. PC-SAFT reduced mean temperature RMSE relative to the Henry-law calculation with only a modest median-runtime increase. This makes PC-SAFT a recommended middle-ground option for future absorption-column simulation studies that need more thermodynamic structure than idealized Henry-law closure but do not yet require a fully calibrated activity-coefficient model. A fully electrolyte-reactive thermodynamic treatment should be validated as a future extension rather than inferred from the present fugacity-coefficient comparison. The SRP/NCCC method contrast also shows how solver choice changes runtime and conditioning under the same governing equations. The central conclusion is that shared benchmark data, explicit solver settings, residuals, and runtime reporting provide a stronger basis for evaluating this class of absorber model than a single successful case study.
