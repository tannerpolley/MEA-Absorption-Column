    \section{Conclusion}
        This work uses a simplified MEA absorber model to benchmark numerical solution methods and thermodynamic driving-force assumptions. The evidence extends beyond a single illustrative validation case by adding one-bed NCCC metrics, solver information, boundary residuals, temperature-profile evidence, method contrasts, and ePC-SAFT fugacity-coefficient comparisons. To the authors' knowledge, the ePC-SAFT contribution is the first absorber-column benchmark in which a full ionic liquid-side ePC-SAFT fugacity calculation is evaluated inside the CO$_2$ thermodynamic driving force. The vapor-side fugacity is evaluated with the same framework in its neutral limit.

        Both thermodynamic calculations converged for the accepted one-bed validation rows and stayed near the measured capture values. ePC-SAFT gave a capture mean absolute error of 3.73 percentage points, compared with 3.78 percentage points for Henry-law closure, while median runtime increased from \SI{8.62}{s} to \SI{9.86}{s}. The full nine-species activity-coupled ePC-SAFT speciation sweep also converged for all seven 2017 C rows with chemistry residuals below $10^{-8}$, zero invalid states, and zero guard penalties. Its mean runtime of \SI{171.102}{s} shows why it is better treated as the next acceleration target rather than the routine model for this benchmark. These results support ePC-SAFT as a practical absorber-column fugacity closure when the goal is more thermodynamic structure than Henry-law closure without losing repeated-run feasibility. The method contrast also shows how solver choice changes runtime and conditioning under the same governing equations, including a fast shooting result on smoother high-liquid-to-gas-ratio rows. The central conclusion is that shared benchmark data, explicit solver settings, residuals, and runtime reporting provide a stronger basis for evaluating this class of absorber model than a single successful case study.
