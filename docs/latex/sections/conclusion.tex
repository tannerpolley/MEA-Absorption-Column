    \section{Conclusion}
        This work uses a simplified MEA absorber model to benchmark numerical solution methods and thermodynamic driving-force assumptions. The evidence extends beyond a single illustrative validation case by adding one-bed C-case metrics, solver information, boundary residuals, temperature-profile evidence, SRP-style method contrasts, and ePC-SAFT fugacity-coefficient sensitivity calculations. To the authors' knowledge, the ePC-SAFT contribution is the first absorber-column benchmark in which a full ionic liquid-side ePC-SAFT fugacity calculation, using the selected fitted-Born SSM+DS option set, is evaluated inside the CO$_2$ thermodynamic driving force. The vapor-side fugacity is evaluated with the same framework in its neutral limit.

        Both thermodynamic calculations converged for all seven one-bed C cases and stayed below ten percentage points of absolute capture error. ePC-SAFT reduced capture MAE relative to the Henry-law calculation, while temperature-profile RMSE stayed essentially comparable and median runtime increased from about 14 to 19 seconds. The full activity-coupled ePC-SAFT speciation proof also converged for Case 3C, giving \SI{89.837}{\percent} capture with chemistry residuals near $10^{-8}$, but its \SI{129.282}{s} runtime shows why it is better treated as the next accelerated path rather than the routine model for this benchmark. Together, these results make ePC-SAFT a useful middle-ground option for future absorption-column simulation studies that need more thermodynamic structure than idealized Henry-law closure while still preserving practical runtime. The SRP/NCCC method contrast also shows how solver choice changes runtime and conditioning under the same governing equations. The central conclusion is that shared benchmark data, explicit solver settings, residuals, and runtime reporting provide a stronger basis for evaluating this class of absorber model than a single successful case study.
