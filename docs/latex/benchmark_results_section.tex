    \subsection{Benchmark Evidence Boundary}
        The paper-facing validation evidence is restricted to generated one-bed C-case artifacts, one-bed ePC-SAFT fugacity-driving-force comparisons, and SRP-style method-contrast diagnostics. Primary validation rows must use common benchmark settings and must report convergence status, residuals, capture error, temperature-profile error where measured taps are available, and runtime. Diagnostic method-comparison rows are retained because they explain solver behavior, but they are not counted as primary NCCC validation.

        This evidence boundary is intentionally conservative. It keeps the manuscript focused on reproducible one-bed validation and thermodynamic sensitivity rather than broader process claims that would require additional plant data, calibration, and holdout validation.
