    \begin{abstract}
        Post-combustion carbon capture (PCC) using amine-based absorption is a critical technology for mitigating CO$_2$ emissions from industrial processes and power generation. This study presents a transparent Python framework for a steady-state MEA absorber model and uses it as a reproducible benchmark for numerical solution strategies and thermodynamic driving-force assumptions. The framework couples mass and energy balances with simplified thermodynamic, transport, reaction-enhancement, and hydraulic submodels. The numerical comparison evaluates shooting, finite-difference, and collocation boundary-value solvers using explicit settings for mesh size, tolerances, initialization, scaling, residual definitions, and software environment. The thermodynamic comparison contrasts the original Henry-law CO$_2$ fugacity driving force with PC-SAFT fugacity-coefficient calculations while retaining the same concentration-based chemical-equilibrium calculation. To the authors' knowledge, the novel element is embedding PC-SAFT fugacity-coefficient calculations on both the vapor and liquid sides of the CO$_2$ driving force inside a solved packed-column absorber benchmark, rather than using PC-SAFT only as a standalone phase-equilibrium calculation. Validation is reported across the one-bed NCCC benchmark cases, with capture-rate error, temperature-profile error where measurements are available, convergence information, and runtime used to document the comparison. The PC-SAFT calculation is slower than the Henry-law baseline but remains fast enough for repeated benchmark calculations, making it a practical middle-ground thermodynamic option when a physics-based equation of state is desired without moving directly to a more heavily parameterized activity-coefficient model. The contribution is therefore a reproducible benchmark and modeling framework for solver comparison and controlled thermodynamic sensitivity, not a claim of a new high-fidelity MEA thermodynamic model or an industrial scale-up tool.
    \end{abstract}
