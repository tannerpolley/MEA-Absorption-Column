    \begin{abstract}
        Post-combustion carbon capture (PCC) with amine absorption is a common reference process for reducing CO$_2$ emissions from industrial and power-generation sources. This study uses a steady-state MEA absorber model as a benchmark for numerical solution methods and thermodynamic driving-force assumptions. The model couples mass and energy balances with simplified thermodynamic, transport, reaction-enhancement, and hydraulic submodels. The numerical comparison evaluates shooting, finite-difference, and collocation boundary-value solvers with reported mesh sizes, tolerances, initialization, scaling, residual definitions, and software environment. The thermodynamic comparison replaces the Henry-law CO$_2$ fugacity driving force with ePC-SAFT fugacity-coefficient calculations while keeping the same concentration-based chemical-equilibrium calculation. To the authors' knowledge, the novel element is embedding a full ionic ePC-SAFT liquid-side fugacity calculation, using the selected 2025 fitted-Born SSM+DS option set, inside a solved packed-column absorber benchmark; the vapor-side calculation uses the same ePC-SAFT framework in its neutral limit because no ionic species are present in the gas phase. ePC-SAFT supplies residual-Helmholtz and electrolyte contribution terms used to compute the fugacity coefficients, and the absorber driving-force calculation then uses those fugacities in the column balances. Validation is reported across the one-bed NCCC benchmark cases using capture error, temperature-profile error where measurements are available, convergence information, and runtime. ePC-SAFT is slower than the Henry-law baseline but remains fast enough for repeated benchmark calculations. It gives a practical middle-ground thermodynamic option when a physics-based electrolyte equation of state is desired without moving directly to a more heavily parameterized activity-coefficient model. The contribution is a reproducible benchmark for solver comparison and controlled thermodynamic sensitivity, not a new high-fidelity MEA thermodynamic model or an industrial scale-up tool.
    \end{abstract}
