    \begin{abstract}
        Post-combustion carbon capture with aqueous monoethanolamine (MEA) is a mature process, but absorber studies often mix changes in thermodynamics, numerical method, and validation scope. This work uses one steady-state packed-column MEA model as a controlled benchmark for two questions: how boundary-value problem solvers behave on the same absorber equations, and how the CO$_2$ driving force changes when Henry-law fugacity closure is replaced by ePC-SAFT fugacity coefficients. The routine campaign holds chemical equilibrium, enhancement factors, transport correlations, hydraulics, and balances fixed, so the thermodynamic comparison isolates the fugacity calculation. To the authors' knowledge, this is the first solved packed-column absorber benchmark to embed a full ionic liquid-side ePC-SAFT fugacity calculation in the CO$_2$ driving force; the vapor side uses the same framework with only neutral species present. Across the accepted one-bed NCCC validation rows, ePC-SAFT gives a capture mean absolute error of 3.73 percentage points, compared with 3.78 percentage points for Henry-law closure, while median runtime increases from \SI{8.62}{s} to \SI{9.86}{s}. Collocation is the most reliable reference solver for the NCCC validation rows, while shooting remains fast on smoother SRP-like cases. The benchmark therefore positions ePC-SAFT as a practical middle-ground thermodynamic model for absorber simulations that need more structure than Henry-law closure without losing repeated-run speed.
    \end{abstract}
