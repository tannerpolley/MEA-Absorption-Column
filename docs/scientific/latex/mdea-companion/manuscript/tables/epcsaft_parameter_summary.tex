\noindent The routine fugacity campaign uses the first six species. The final three species occur only in the nine-species feasibility calculation. The retained parameter record does not contain complete source and estimation details for the neutral species. The \ce{MEAH+} and \ce{MEACOO-} values were retained from an earlier evaluation, the \ce{HCO3-} value was transferred for the numerical test, and the \ce{CO3^2-}, \ce{H3O+}, and \ce{OH-} values are assumptions used only in that test. The nine-species set is therefore used for a conditional numerical-coupling calculation and is not presented as a predictive parameterization.

\noindent The selected parameter set contains one nonzero pair coefficient, $k_{\ce{MEA},\ce{H2O}}=-0.052$. This value was retained from an earlier MEA--water record, but its source dataset, fitting procedure, and uncertainty were not recovered. The earlier record also used a different neutral association-scheme combination from the selected 2B/2B record. This inconsistency must be resolved and the calculations repeated before the parameter set can be presented as source-complete.
