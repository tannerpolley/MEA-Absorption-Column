# MDEA research journal

This is the cumulative, claim-gated record for extending the absorber model from MEA to MDEA.
It is not a second manuscript and contains no admitted MDEA result at initialization.

Keep source evidence and input identity in the ledgers before adding a calculation. Record
failed or diagnostic calculations in the methods narrative, but do not populate the results
section until the promotion gates are satisfied.

Build locally with:

```bash
latexmk -xelatex -interaction=nonstopmode -halt-on-error -outdir=builds main.tex
```
