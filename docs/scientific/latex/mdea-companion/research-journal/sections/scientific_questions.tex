\section{Scientific questions}

The extension must answer the following questions without changing the frozen MEA result.

\begin{enumerate}
  \item Can one immutable reactive ePC-SAFT parameter set evaluate every admitted MDEA
  pressure row and every admitted speciation state without failed admitted rows?
  \item Does the reactive model reproduce the admitted aqueous MDEA speciation and full
  bubble-pressure/VLE domain with thermodynamically consistent fugacity conventions?
  \item Are the derivatives required by equilibrium and column solvers finite, stable, and
  consistent with independent numerical checks over the admitted domain?
  \item Does the generic amine contract reproduce the existing MEA column result and permit
  an MDEA run only when all solvent-specific inputs are supplied?
  \item Does the completed MDEA column model reproduce source-backed capture and temperature
  observations without solvent-specific tuning hidden in the column code?
\end{enumerate}
