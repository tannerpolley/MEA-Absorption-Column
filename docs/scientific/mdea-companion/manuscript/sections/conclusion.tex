    \section{Conclusion}
        This work uses a simplified MEA absorber model to benchmark numerical solution methods and thermodynamic driving-force assumptions under a fixed set of governing equations. The evidence extends beyond a single illustrative validation case by adding one-bed NCCC metrics, attempted-case accounting, solver information, boundary residuals, temperature-profile evidence, method contrasts, and ePC-SAFT fugacity-coefficient comparisons. To the authors' knowledge, the ePC-SAFT contribution is the first absorber-column benchmark in which a liquid-side ionic ePC-SAFT CO$_2$ fugacity calculation is evaluated inside the thermodynamic driving force while concentration-based chemical equilibrium, enhancement, transport, hydraulics, and balances remain fixed. The vapor-side fugacity is evaluated with the same framework in its neutral limit.

        Both thermodynamic calculations converged for the accepted one-bed validation rows and stayed near the measured capture values. ePC-SAFT gave a capture mean absolute error of 3.32 percentage points, compared with 3.14 percentage points for Henry-law closure, while median runtime increased from \SI{5.25}{s} to \SI{7.70}{s}. The archived nine-species activity-rebased sweep also converged for all seven 2017 C rows with chemistry residuals below $10^{-8}$, zero invalid states, and zero guard penalties, but its capture accuracy was uneven and its mean runtime was \SI{171.102}{s}. Because each local reaction constant was anchored to the legacy-derived initial composition, this legacy-interface result demonstrates numerical activity coupling rather than independently predictive reactive thermodynamics. The routine results support ePC-SAFT as a practical CO$_2$ fugacity-closure option when the goal is an electrolyte equation-of-state driving force at repeated-run cost. The solver comparison also shows how method choice changes runtime and conditioning under the same governing equations. Shared benchmark data, explicit solver settings, residuals, and runtime reporting provide a stronger basis for evaluating this class of absorber model than a single successful case study.

        These conclusions apply to the selected MEA parameter set, fixed transport and enhancement correlations, one-bed NCCC case set, and archived numerical diagnostics. The study does not propagate thermodynamic or transport uncertainty, establish independent cross-facility validation, identify an optimal operating condition, or demonstrate a plug-in extension to another amine. Predictive nine-species chemistry requires independently sourced activity-basis equilibrium constants and a provenance-complete parameter set. Extension to another solvent requires solvent-specific chemistry, thermodynamic parameters, properties, kinetics, and absorber validation.
