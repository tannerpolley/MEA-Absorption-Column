    \section*{Code Availability}
The Python code for the MEA absorber benchmark, including the solver settings and thermodynamic driving-force calculations used in this study, is available in the \href{https://github.com/tannerpolley/MEA-Absorption-Column}{project repository}; the MEA-only manuscript and evidence state preserved before MDEA companion work is available at the \href{https://github.com/tannerpolley/MEA-Absorption-Column/tree/nce-mea-only-pre-mdea-2026-08-25}{MEA-only pre-MDEA freeze tag dated 2026-08-25}. The reported ePC-SAFT validation tables retain the repository-distributed \texttt{MEA\_CO2\_H2O\_ionic\_fit} parameter artifact and the package identity recorded by their archived run workflow. The current adapter targets the non-editable \texttt{epcsaft} 0.2 wheel through its public \texttt{Parameters--Mixture--State} API. The final integration gate binds Engine commit \texttt{b64f6df} and wheel SHA-256 prefix \texttt{a505d20a}; the complete identities are recorded in the repository integration contract. Substituting either the package or parameter artifact requires regenerating the affected benchmark evidence. The Engine source is cited with the software reference~\cite{Polley2026epcsaft}. No archival DOI has been minted for the absorber repository at the time of manuscript preparation; the cited GitHub tag should be used for reproduction until an archive is issued.
