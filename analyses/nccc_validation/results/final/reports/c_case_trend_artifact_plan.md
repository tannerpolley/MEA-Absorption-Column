## 2) Paper-facing inclusion (recommended)

### A. 1C→7C capture-error trend
Use the full-case benchmark artifact:
- Figure: `analyses/nccc_validation/results/final/figures/c_case_thermo_benchmark.pdf`
- Supporting table: `analyses/nccc_validation/results/final/tables/verified_c_case_thermo_benchmark.csv`

Evidence basis:
- Capture error shifts from undercapture at 1C (both models: about `-18%`) to near-correct at 3C (about `0%`) and overcapture at 7C (both models: about `+22%`).
- Temperature RMSE remains moderate for 1C/3C/7C (`3.94–7.70 K` depending model), so this is a valid capture-bias trend figure, but not a full physics-tradeoff statement by itself.

### B. Profile overlay (conservative, low-risk)
Use one compact, strict paper candidate figure:
- `analyses/nccc_validation/results/final/figures/c_case_temperature_profile_overlay_recommended_compact.pdf`
- Copy in manuscript figure folder: `docs/latex/figures/case-c-temperature-overlay.pdf`

Panel recommendation:
- Include `3C` as the anchor case.
- Include `6C` as the only additional case beyond `3C`.

Why:
- Inclusion rule used from existing profile diagnostics: `|capture_error_pct| <= 10%` **and** tap RMSE `<= 9.0 K`.
- Best tap-fit summary (tap RMSE metric, from `c_case_profile_tap_metrics.csv`):
  - `3C`: `capture_error_pct = +0.198%`, `tap_rmse_K = 9.316 K` (slightly misses strict RMSE criterion)
  - `6C`: `capture_error_pct = +9.970%`, `tap_rmse_K = 8.603 K` (passes both criteria)
  - `7C`: `capture_error_pct = +22.073%` (fails capture criterion)
- Figure includes both thermo model profiles (ideal Henry/ePC-SAFT), NCCC tap markers, and explicit title text with ePC-SAFT capture error per panel.

## 3) Diagnostic-only artifacts (do not elevate to manuscript claims)

- `analyses/nccc_validation/results/runs/c_case_trend_*`:
  - These are model-fix/stability perturbation screens, not a clean case-complete sweep.
  - In `c_case_trend_*`, `7C` is highly unstable: only ~6/10 successful rows vs 8/8 for `1C,3C`; several 7C runs are timeouts.
  - Successful 7C perturbations show large spread (`~-47%` to `+23%` capture error), which is inconsistent with a single “fixed” trend statement.
- `analyses/nccc_validation/results/runs/c_case_trend_sensitivity_smoke`:
  - 1C/3C run; 7C fails under all sensitivity modes (subprocess timeout).
  - Useful only for solver robustness triage, not for manuscript validation.

## 4) Overclaim guards
- Do not claim that model-fix perturbation cases imply monotonic validity of 7C.
- Do not claim 6C is fully “validated” as part of the trend claim line; treat it as a constrained profile add-on.
- In text, phrase 7C with explicit caveats: high capture bias, intermittent convergence failures, and sensitivity-run instability.
- Keep the primary manuscript narrative on:
  1) 1C–3C anchor behavior, and
  2) a conservative extra profile check at 6C.
